Alvarez Lab Automation

Alvarez Lab Automation is a personal software development project focused on building reusable tools for application monitoring, reporting, and automated email notifications.

Gmail Integration

The application uses Google's Gmail API to send authorized email notifications and reports from the owner's Google account.

Gmail access is limited to sending email. The application does not request permission to read, modify, or delete inbox messages.

Security

The email service runs locally on the owner's Windows computer. OAuth credentials are protected using Windows encryption and are not published with the website.
