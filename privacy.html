Privacy Policy

Alvarez Lab Automation

Last updated: November 11, 2026

Overview

Alvarez Lab Automation is a personal software application used by its owner to send automated email notifications, application status alerts, and reports.

Google Account Access

The application requests the Gmail API permission https://www.googleapis.com/auth/gmail.send to send email on behalf of its authorized user.

The application does not request permission to read, modify, or delete Gmail inbox messages.

Information Processed

The application processes email recipient addresses, subject lines, message bodies, and OAuth authentication credentials necessary to send authorized messages.

Data Storage and Security

OAuth credentials are stored locally on the owner's Windows computer using Windows Data Protection API (DPAPI) encryption. Credentials are not published with the website or source code.

Data Sharing

The application sends email content and recipient information to Google's Gmail API for delivery. It does not sell user data or share Google account information with advertisers.

Data Retention and Deletion

OAuth credentials are retained locally until removed or revoked by the owner. The owner can revoke access through Google Account security settings and delete locally stored credentials.

Contact

Questions about this policy can be sent to ralvarez.labs@gmail.com.
